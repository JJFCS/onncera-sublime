# SEB - SUBLIME EMACS BINDING

- GIT CLONE THE REPO THROUGH GITHUB
- GET IT INTO THE RIGHT SUBLIME DIRECTORY
- GO TO THE PACKAGES DIRECTORY THEN RENAME THE FOLDER AS "User"
- LAUNCH SUBLIME , OPEN THE COMMAND PALETTE AND INSTALL PACKAGE CONTROL

## REPOSITORY STRUCTURE ON MAC OS
- macOS: ~/Library/Application Support/Sublime Text/Packages
